# Local Setup

The canonical Windows instructions are maintained in the repository-root
[SETUP_GUIDE.md](../SETUP_GUIDE.md). They contain current backend/frontend
ports, environment setup, verification URLs, authentication caveats, and the
classifier checkpoint status.

Use the repository root as the project directory. The old `RJ147-Smart-Waste`
paths and port `8000` are not applicable to this checkout; the local Vite proxy
expects the API at `127.0.0.1:8001`.
